# Project Instructions

## Product Preferences

- Vertical real estate is precious. Prefer compact, information-dense layouts over tall decorative sections.
- Avoid wasting vertical space with oversized headers, generous empty bands, or card stacks that force unnecessary scrolling.
- Scrolling should be required only when the workflow genuinely needs more content than the viewport can hold.
- The app must remain responsive and adaptive for mobile web views.
- Mobile layouts should preserve core workflows without horizontal overflow, clipped controls, or text overlap.
- Use responsive grids, wrapping controls, compact spacing, and stable component dimensions so desktop and mobile views both remain usable.
